# Tally

A mobile-first, frontend-only personal finance demo built with Expo, React Native, TypeScript, and Expo Router. Receipt history and the shopping list are stored locally on the device with AsyncStorage. There is no backend or account setup.

## Run with Expo

```sh
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `w` to open the web version. Use `a` or `i` for an Android emulator or iOS simulator. The app is designed for a 390 × 844 phone viewport. Reset demo data from the Group tab’s settings area.

## Screens

Home, Dashboard, Scan and review, Receipt Detail, Shopping List, Compare, Predict, Rewind, and Group.
